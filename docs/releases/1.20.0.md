## Four starter vaults for every language

Each language ZIP now contains:

- **LifeOS Vault**: a working PARA example.
- **LifeOS Blank Vault**: PARA templates and settings for your own notes.
- **LifeOS Theme Vault**: a working theme-note example without mandatory PARA.
- **LifeOS Theme Blank Vault**: plain-theme templates and settings.

The new theme example includes linked daily records, tasks, reference notes and a related theme. A tagged habit entry demonstrates the record-query filtering rules. Theme daily templates include snapshots when LifeOS creates a new daily note.

Use [open-source LifeOS 1.29.0](https://github.com/quanru/obsidian-lifeos/releases/tag/1.29.0) or newer. Install LifeOS and Dataview from Obsidian Community plugins; plugin binaries are not bundled. All ten languages remain available, and existing PARA vault names and download filenames are retained.
