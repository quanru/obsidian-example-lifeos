# LifeOS Examples 1.11.0

Ten languages, with both an example vault and a blank vault in each download: English, Simplified Chinese, Traditional Chinese, German, Spanish, French, Portuguese, Japanese, Korean, and Arabic.

Folder settings, templates, starting guides, installation instructions, daily records, and sample project queries match the open-source LifeOS plugin. The blank variant keeps the structure and guides without sample journal entries or projects.

## Installation

Requires **LifeOS 1.28.0 or newer** and Obsidian 1.4.0 or newer. Extract the language ZIP, choose `LifeOS Vault` or `LifeOS Blank Vault`, and open that folder as a vault. Install and enable LifeOS from Community plugins. Install Dataview for LifeOS query blocks; setup, capture, and weekly review work without it.

Packages contain starter content and public settings only. Install plugin binaries separately. Historical content in the repository remains available but is no longer included in these release downloads. Existing archive names are preserved; `LifeOS_KO.zip` adds Korean.

The template language stays fixed for each vault. Switching the plugin display language does not translate or rename existing notes.
