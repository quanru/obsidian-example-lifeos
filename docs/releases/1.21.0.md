# LifeOS Examples 1.21.0 — Theme workflows and refreshed starters

- Try complete Chinese and English workflows for learning TypeScript and launching a personal site. Each includes unfinished and completed tasks, daily records and tagged resources. A habit entry demonstrates the exclusion rules.
- Start new theme overviews with unfinished tasks and the independent LifeOSOpen query syntax.
- Follow the updated Dataview setup and selective query-upgrade guidance.
- Use the bundled MIT-licensed Aino 1.0.8 theme as the default appearance. The theme requires Obsidian 1.10.6 or newer.

Requires [open-source LifeOS 1.29.2](https://github.com/quanru/obsidian-lifeos/releases/tag/1.29.2) or newer. Install LifeOS and Dataview separately. Plugin binaries, activation data and Pro resources are not bundled.

Ten language packages remain available. Each ZIP includes PARA example and blank vaults plus plain-theme example and blank vaults. Existing download filenames are retained. Existing user vaults do not need to be replaced.
