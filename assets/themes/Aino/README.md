# Aino 主题资源

资源来自 [Aino 公开发行版 1.0.8](https://github.com/quanru/aino-obsidian-theme/releases/tag/1.0.8)，采用 MIT 许可证。

`manifest.json` 和 `theme.css` 保留发行附件原文，`LICENSE` 来自同一标签。生成脚本将它们放入每个示例库和空白库，并在 `.obsidian/appearance.json` 中默认选择 Aino。

更新时，从公开发行版下载这三个文件，再运行 `node scripts/examples/generate.mjs` 和 `node scripts/examples/generate.mjs --check`。不要读取或复制 Pro 仓库的资源。
