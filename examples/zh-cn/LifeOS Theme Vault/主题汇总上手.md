# 主题汇总上手

此页示例需搭配开源版 LifeOS 1.29.2 或更新版本，任务汇总默认只显示未完成项。

1. 打开 [[主题/学习 TypeScript/README.md|学习 TypeScript]]，查看一条待办、一条记录和一篇资料。
2. 勾选待办，再打开 [[0. 周期笔记/2026/Daily/10/2026-10-15.md|来源日记]]，确认原任务已完成；习惯任务不会收录。
3. 打开 [[主题/发布个人网站/README.md|发布个人网站]]：项目也可以是普通主题，不需要 PARA 目录。
4. 在快速记录中关联其中一个主题，保存新内容后回到汇总页；展开“收录规则”查看标签和过滤范围。

任务显示未完成项；记录链接返回来源，资料链接打开原笔记。两篇主题使用不同标签，彼此不会混入。

旧主题页或已配置的模板可使用命令“LifeOS: 升级主题查询”，逐项预览并应用标准查询的改动。保留全部任务时不要勾选对应任务块。查询需要单独安装并启用 Dataview；快速记录、主题创建和原生主题列表不需要。
