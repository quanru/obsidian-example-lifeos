# Theme overview walkthrough

These examples require open-source LifeOS 1.29.2 or newer. Task overviews show unfinished items by default.

1. Open [[Themes/Learn TypeScript/README.md|Learn TypeScript]] to see one open task, one record and one resource.
2. Check the task, then open the [[0. Periodic Notes/2026/Daily/10/2026-10-15.md|source journal]] to verify writeback. The habit task is excluded.
3. Open [[Themes/Launch a personal site/README.md|Launch a personal site]]. Projects can be plain themes without PARA folders.
4. Associate either theme in Quick capture, save new content and return to its overview. Expand Inclusion rules to see tags and filters.

Tasks show unfinished items; record links return to their source and resource links open the original note. Distinct tags keep the two themes separate.

For an older theme index or configured template, run LifeOS: Upgrade theme queries and review the changes before applying. Leave a task block unselected to retain completed tasks. Queries require Dataview to be installed and enabled separately; Quick capture, theme creation and native theme lists do not.
