# LifeOS

1. Abra esta pasta como cofre no Obsidian.
2. Instale e ative LifeOS (`periodic-para`) e Dataview em Configurações → Plugins da comunidade.
3. Execute o comando de configuração do LifeOS ou abra o guia inicial. Os modelos existentes e seu idioma são mantidos.

Não inclui binários de plugins, dados pessoais de contas ou recursos do Pro.
