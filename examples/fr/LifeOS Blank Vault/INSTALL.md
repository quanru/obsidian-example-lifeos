# LifeOS

1. Ouvrez ce dossier comme coffre dans Obsidian.
2. Installez et activez LifeOS (`periodic-para`, ≥ 1.28.0) et Dataview dans Paramètres → Modules complémentaires.
3. Exécutez la commande de configuration LifeOS ou ouvrez le guide de démarrage. Les modèles existants et leur langue sont conservés.

Aucun binaire de module, donnée personnelle de compte ou ressource Pro n’est inclus.
