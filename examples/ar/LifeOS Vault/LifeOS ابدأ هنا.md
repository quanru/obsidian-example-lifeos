# LifeOS ابدأ هنا

ابدأ بمحتواك الحقيقي خلال خمس دقائق.

> سجّل → اربط بمشروع أو مجال → استخدم الموارد → أرشف.

## الدقائق الخمس الأولى

- [ ] فتح اليوم
- [ ] تسجيل فكرة حقيقية
- [ ] إنشاء مهمة تالية محددة
- [ ] الربط بـ PARA عند الحاجة
- [ ] كتابة المراجعة الأسبوعية

## نقاط العمل

- فتح اليوم: `0. الملاحظات الدورية`
- المشاريع: `1. المشاريع`
- المجالات: `2. المجالات`
- الموارد: `3. الموارد`
