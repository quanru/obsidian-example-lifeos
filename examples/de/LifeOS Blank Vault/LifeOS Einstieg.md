# LifeOS Einstieg

In fünf Minuten mit eigenen Inhalten beginnen.

> Erfassen → Projekt oder Bereich zuordnen → Ressourcen nutzen → archivieren.

## Die ersten fünf Minuten

- [ ] Heute öffnen
- [ ] Einen echten Gedanken erfassen
- [ ] Eine konkrete nächste Aufgabe anlegen
- [ ] Bei Bedarf mit PARA verbinden
- [ ] Den Wochenrückblick ausfüllen

## Arbeitsziele

- Heute öffnen: `0. Periodische Notizen`
- Projekte: `1. Projekte`
- Bereiche: `2. Bereiche`
- Ressourcen: `3. Ressourcen`
